
# Booklet

Booklet is a simple and interactive frontend web application developed using HTML, CSS, and JavaScript. The main purpose of this project is to help users organize and manage their personal book notes in a clean and user-friendly way. Instead of writing notes on paper or saving information in different places, users can store important book details directly inside the web application.

This application allows users to add book information such as the Book Name, Author Name, and Description through an attractive popup interface. Once the details are entered, the book note is dynamically displayed on the webpage as a separate card. Users can also remove unwanted notes instantly using the delete option provided in each book card. The entire project is designed with a modern UI layout to provide a smooth and comfortable user experience.

The project focuses mainly on DOM manipulation and event handling in JavaScript. Dynamic elements are created using JavaScript functions, making the webpage more interactive and responsive. CSS is used to design the layout, popup box, buttons, overlays, and book cards with a clean visual appearance. HTML is used to structure the webpage elements properly.

One of the major highlights of this project is its simplicity and usability. The interface is designed in such a way that even beginner users can easily understand and use the application without confusion. This project also helped improve frontend development skills such as handling user input, creating dynamic content, styling responsive components, and managing UI interactions.


## Features

- Add new book notes dynamically
- Store book title, author name, and description
- Delete notes instantly
- Interactive popup input form
- Simple and modern user interface
- Fully developed using frontend technologies only


## Tech Stack

**Frontend** HTML, CSS, JS
